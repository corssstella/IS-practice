Создание локального репозитория

В GitHub Desktop нажмите «Создать новый репозиторий на вашем локальном диске».

Присвойте репозиторию имя, например learning-git.

Выберите «Инициализировать этот репозиторий с помощью README», чтобы автоматически создать файл README.md.

Совет. Файл README.md содержит информацию о проекте и помогает другим пользователям понять, настроить и запустить его.

Нажмите «Создать репозиторий».


Клонирование репозитория

Когда вы создаёте репозиторий на GitHub, он существует как удалённый репозиторий. Вы можете клонировать репозиторий, чтобы создать локальную копию на компьютере и выполнять синхронизацию между двумя расположениями.

Клонирование репозитория

На GitHub перейдите на главную страницу репозитория.

Над списком файлов нажмите кнопку Code.

Скопируйте URL-адрес репозитория.

Чтобы клонировать с помощью HTTPS, выберите вкладку HTTPS и нажмите значок копирования.

Чтобы клонировать с помощью SSH, выберите вкладку SSH и нажмите значок копирования.

Откройте Git Bash.

Перейдите в папку, где должна находиться локальная копия:
cd путь_к_папке

Введите команду:
git clone скопированный_URL_адрес

Нажмите Enter.

Пример:
$ git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
